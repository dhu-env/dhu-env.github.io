# 🛠 站点完善指南

本指南面向**网站维护者**，说明站点中每一处「该部分待完善」的内容应该如何补齐，以及如何新增课程、更新信息、本地预览与部署上线。

---

## 0. 站点结构速览

本站是 MkDocs（Material 主题）项目，部署到 GitHub Pages。目录结构如下：

```
DHU-Env.github.io/
├── mkdocs.yml                  # 站点配置与导航（由生成器自动写入，勿手改）
├── README.md                   # 项目说明与部署摘要
├── .github/workflows/ci.yml    # GitHub Actions 自动部署脚本
├── tools/
│   ├── _generate_site.py       # 站点生成器（唯一入口，见第 3 节）
│   ├── _manual_docs/           # 手工维护页面源（首页/贡献指南/完善指南），生成时拷贝到 docs/
│   └── *_data.py               # 教学计划数据（课程编号/学分/学期等）
└── docs/
    ├── index.md                # 首页（由 tools/_manual_docs/index.md 拷贝）
    ├── guideline.md            # 平台贡献指南（投稿规则）
    ├── 完善指南.md              # 本文件（不进站点导航，仅本地维护参考）
    ├── courses.md              # 本科课程大纲（总导航）
    ├── images/logo.png         # 站点 Logo（学院院徽，透明底 PNG）
    ├── stylesheets/extra.css   # 自定义样式（课程页顶部“所属专业”状态栏等）
    └── courses/
        ├── public/
        │   ├── index.md        # 公共基础课程导航页（分类表格）
        │   └── fundamental/    # 公共基础课程（数理/化学/力学/机械制图/电学/计算机），平铺单文件
        └── routes/             # 六个专业方向
            ├── EnergyEnv/      # 能源与环境系统工程（能环）
            ├── EnvEngExcellent/# 环境工程（卓越班）（环卓）
            ├── EnvEngDual/     # 环境工程（环境工程与工商管理双学位）（环管）
            ├── EnvScience/     # 环境科学（环科）
            ├── BuildingEnv/    # 建筑环境与能源应用工程（建环）
            └── CivilGreen/     # 土木工程（绿色建造）（土木）
```

每门专业课程对应一个**以课程名命名的文件夹**（如 `docs/courses/routes/EnergyEnv/流体力学/`），内含：
- `index.md`：课程页面（顶部状态栏 + 课程基本信息表 + 课程资源 / 学习笔记 / 学习建议等待完善小节）；
- 该课程的资源文件直接放同文件夹（如 `流体力学/复习笔记.pdf`），页面内用相对路径引用。
**所有课程页面当前统一为「顶部状态栏 + 课程基本信息表 + 课程资源 / 学习笔记 / 学习建议等待完善小节」的骨架**，补齐内容就是编辑对应 `index.md`。

### 0.1 课程分类与命名规则（重要）

- **页面划分规则（以「课程编号」为准）**：课程编号完全一致的课程本质是同一门课，**合并为同一个页面**，页面标题即为课程名本身、**不加专业括号备注**（如六个专业共同的 `高等数学类`、能环与土木共同的 `理论力学(1)`）；课程名称相同但课程编号不同的，**不合并、不加后缀**，分别在各自专业目录下建立独立页面，例如能环的 `工程热力学` 与建环的 `工程热力学` 是两个页面（编号 140083 / 140084）。
- **专业缩写对照**：能环＝能源与环境系统工程；环卓＝环境工程（卓越班）；**环管＝环境工程（环境工程与工商管理双学位）**；环科＝环境科学；建环＝建筑环境与能源应用工程；土木＝土木工程（绿色建造）。顶部导航与侧边导航的一级标题按以上缩写显示。
- **状态栏**：每门课程页面标题下方有绿色「**所属专业**」状态栏，列出本页面对应的专业标签；**标签可点击**，跳转到对应专业的方向导航页，便于按专业快速索引；各专业方向导航页顶部也有「专业方向」状态栏。
- **文件归属**：多专业共有的基础学科课程放在 `courses/public/fundamental/`（导航「公共基础课程」）；仅单个专业（或同码合并后归属某专业目录）的课程放在 `courses/routes/<方向>/<课程名>/` 下，**没有独立的「公共专业课程」区**——各专业方向页与侧边导航均完整列出本专业培养方案课程，跨专业重叠课程经链接直接跳转到对应课程页面（同一页面、不做重复建设），侧边栏仍停留在当前专业目录。
- **修读学期表达**：课程页「建议修读学期」统一采用「大一上 / 大一下 / 大二上 / 大二下 / 大三上 / 大三下 / 大四上 / 大四下」的年级表达（由教学计划的第 1～8 学期换算，第 1 学期＝大一上，依次顺延）。

## 1. 课程页面的各个「待完善」部分怎么填

每门课程页当前包含「课程基本信息」表与以下待完善小节：**课程资源（推荐教材 / 网课、资源文件）、学习笔记、学习建议**。课程页**不设置**课程大纲、教学进度安排、分数比例等章节（见第 4 节）。逐项说明如下：

### 1.1 推荐教材 / 网课

> 现状：`> 该部分待完善`

**来源**：

- 任课老师指定的教材（书名、作者、出版社、版次）；
- 老师推荐的参考书；
- B 站 / 中国大学 MOOC / 学堂在线等平台的质量较高课程链接。

**填写格式建议**：

```markdown
### 推荐教材 / 网课

- **《工程热力学》（第X版）**，沈维道、童钧耕 编，高等教育出版社
- B站视频：[【工程热力学】8小时速成课](https://www.bilibili.com/...)（xx up主）
- 中国大学MOOC：[工程热力学](https://www.icourse163.org/...)（xx大学）
```

### 1.2 资源文件

> 现状：`> 该部分待完善`

**来源**：

- 学长学姐投稿的课件、复习资料、回忆卷（试卷回忆）；
- 校内网盘/共享链接；
- 官方公开资料。

**填写格式建议**（含「网盘链接」与「回忆卷」两类）：

```markdown
### 资源文件

- [**流体力学 课件合集（百度网盘）**](https://pan.baidu.com/s/xxxx?pwd=xxxx)（提取码：xxxx）
- 回忆卷：
  - [22-23春 流体力学 期末回忆卷](https://...)（by 23级xx）
  - [23-24春 流体力学 期末回忆卷](https://...)（by 23级xx）
```

**注意**：分享链接请勿设置为「永久有效+无提取码」之外的敏感权限；网盘失效后请及时更新。

### 1.3 学习笔记

> 现状：`> 该部分待完善`

**来源**：学长学姐投稿的笔记（PDF / Markdown / Word）。多份笔记可用「标签页」展示（对应 Material 主题的 tabbed 语法）：

```markdown
### 学习笔记

=== "王世贤整理"

    <style>
        .pdf-container {
            width: 100%;
            height: 100vh;
            overflow: auto;
            border: 1px solid rgba(46, 125, 50, .25);
            border-radius: 6px;
        }
        .pdf-container object {
            width: 100%;
            height: 100%;
        }
    </style>

    <div class="pdf-container">
        <object data="复习笔记.pdf" type="application/pdf" aria-labelledby="PDF document">
            <embed src="复习笔记.pdf" type="application/pdf" />
            <p>您的浏览器不支持 PDF 内嵌预览，请下载查看。</p>
        </object>
    </div>
```

**注意**：PDF 文件放在该课程的同名文件夹下（如 `docs/courses/routes/EnergyEnv/流体力学/复习笔记.pdf`），页面内用**相对路径**（直接写文件名）引用；在「学习笔记」上方用 `=== "XX整理"` 标签注明笔记作者（尊重贡献，便于溯源）。浏览器原生 PDF 阅读器自带保存/翻页/搜索功能，无需另加下载链接。

### 1.4 学习建议

> 现状：`> 该部分待完善`

**来源**：学长学姐的课程攻略/心得（投稿或约稿）。

**填写格式建议**：一段 200 字以上的学习心得，可含复习规划、重点章节、踩坑提醒。可用 `=== “作者”` 标签页区分多人投稿（格式同 1.3）。

## 2. 其他页面的待完善内容

### 2.1 专业简介（各专业方向导航页顶部）

> 现状：`!!! info “专业简介” … 该部分待完善`

**来源**：学院官网专业介绍页、招生宣传手册、《本科培养方案》前言。

建议摘录：专业定位、主干学科、核心课程、毕业去向（读研/就业方向）、学院实验平台等，控制在 200-300 字。

### 2.2 通识教育与公共环节总览页

该页底部有「需要补充的内容」段落，可按第 1 节的方法补充各通识课程的**考核方式与教材信息**；如某门通识课资料丰富，可仿照其他课程为该课单独建页（见第 3 节）。

### 2.3 首页与维护者名单

- 首页「常用课程资源」卡片：当某课程资料补齐后可替换或增删卡片；卡片中的课程链接指向 `routes/<方向>/<课程名>/` 的具体页面（如 `./courses/routes/EnergyEnv/流体力学/index.md`）；
- 首页「特别致谢」栏：仅保留“浙江大学的源梦紫金 [ZJUSUEE](https://zjusuee.github.io/)”一项（“源梦紫金 ZJUSUEE”为超链接），不要添加其他平台或个人；
- 「维护者名单」：登记实际维护同学/组织。

## 3. 新增或修改课程

### 3.1 修改已有课程页

直接用任意文本编辑器（VS Code / Typora / 记事本）打开对应课程文件夹下的 `index.md`，按第 1 节格式填写即可。**注意保留文件开头的 front-matter（`--- tags: … ---`）与课程基本信息表**。

### 3.2 新增一门课程页面

1. 新建文件夹与文件：根据课程归属创建，例如公共基础课 → `docs/courses/public/fundamental/新课程名.md`；某专业课程 → `docs/courses/routes/<方向>/新课程名/index.md`；
2. 复制任意一门课程页作为模板，修改标题、课程基本信息（编号/学分/学时/学期/适用专业，可从教务系统或教学计划总揽获取；学期用「大一上/大一下…」表达）；
3. **注意命名规则（见 0.1）**：课程编号一致的课程合并为同一页面（标题不加专业括号、不拆分）；课程编号不同的同名课程，在各自专业目录下各自建页（**不加括号后缀**）；
4. 在 `tools/_generate_site.py` 的课程注册表（`FUND_SECTIONS` / `ROUTE_SECTIONS`）中登记该课程及其所属专业，然后重新运行生成器并构建：
   ```bash
   python tools/_generate_site.py
   mkdocs build
   ```
   各专业方向导航页与侧边导航由生成器按教学计划分类**自动全量生成**（跨专业重叠课程自动链接到对应课程页），无需手动修改 `mkdocs.yml`；
5. **重要**：重新运行生成器会重建全部课程页，**覆盖手工编辑的 `index.md` 内容**（学习笔记、推荐教材等手工补充会被还原为「该部分待完善」）。生成器会自动保留课程文件夹内的**非 Markdown 资源文件**（PDF/图片等），但 `index.md` 中的手工内容不会保留。因此：
   - 每次重跑生成器后，请按第 1 节格式重新补齐手工内容（或将手工内容同步维护进 `tools/_manual_docs/` 或生成器模板）；
   - 如某课程资料丰富且不希望被覆盖，可考虑把该课程页面从生成器注册表中移除（改由 `tools/_manual_docs/` 手工维护），并在导航中登记。
6. 本地预览验证（见第 5 节）。

### 3.3 更新课程信息（学分/学期变化）

课程基本信息表的数据来源于 2023a/2024a 教学计划总揽。若学院更新培养方案，只需修改对应课程页表格中的数值，并在「课程说明」中注明版本。**建议每学期开学后对照教务系统核对一遍各课程页的学期与学分。**

## 4. 说明：为什么课程页没有「分数比例 / 课程大纲 / 教学进度安排」

按建站要求，课程详细页面**不设置分数构成/占比、课程大纲、教学进度安排等章节**，仅保留「课程内容 + 课程基本信息表 + 课程资源（推荐教材 / 网课、资源文件）+ 学习笔记 + 学习建议」等小节。如后续确实需要补充考核方式（如「期末60%+平时40%」），建议在「课程内容」下新增「### 考核方式」小节，并注明信息来源与学年（如「据 23级 同学反馈，仅供参考」），不要与课程内容混在一起。

## 5. 本地预览与部署

### 5.1 本地预览（需要 Python）

```bash
pip install mkdocs-material
mkdocs serve          # 浏览器打开 http://127.0.0.1:8000
```

修改文件后页面会自动刷新；确认无误后执行 `mkdocs build`，生成 `site/` 目录。

### 5.2 部署到 GitHub Pages（推荐，自动）

1. 在 GitHub 新建仓库（例如 `DHU-Env.github.io`，选择 Public）；
2. 将本项目所有文件推送到仓库（含 `.github/workflows/ci.yml`）；
3. 进入仓库 **Settings → Pages**，将 Source 设置为 **Deploy from a branch**，Branch 选择 **gh-pages**、目录保持 **/(root)**；
4. 之后每次 `git push`，GitHub Actions 会自动安装 mkdocs-material、构建站点并发布到 gh-pages 分支，几分钟后即可访问 `https://<用户名>.github.io/DHU-Env.github.io/`（若仓库名为 `<用户名>.github.io`，则为 `https://<用户名>.github.io/`）；
5. 将 `mkdocs.yml` 顶部的 `site_url` 改为实际网址。

### 5.3 手动部署（可选）

```bash
mkdocs gh-deploy --force
```

## 6. 维护注意事项

- **版权**：所有投稿资料严禁商用；转载他人资料需获得授权并注明出处；涉及侵权立即撤除。
- **信息时效**：课程学分/学期/老师安排每年可能变化，页面中尽量注明「xx级整理」；不确定的信息标注来源。
- **命名规范**：文件与文件夹使用课程中文名；笔记 PDF 用「课程名+作者+年份」命名。
- **投稿渠道**：统一邮箱投稿（见 `guideline.md`），由维护者审核后入库，避免多人直接改仓库造成冲突。
