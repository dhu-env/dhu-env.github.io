# 欢迎来到东华环院课程攻略！✨

### 💡 关于本站

Hi~😉！

这里是由**东华大学环境科学与工程学院**建设的课程攻略共享平台——**「东华环院课程攻略」**

学院涵盖<strong>能源与环境系统工程、环境工程（卓越班）、环境工程（环境工程与工商管理双学位）、环境科学、建筑环境与能源应用工程、土木工程（绿色建造）</strong>等专业。本站致力于汇总整合学院各专业的课程资源，满足环院学子日常学习需要，以及度过漫长的考试周🌟

从《流体力学》《工程热力学》到《传热学》《化工原理》，每一门课程都藏着独特的通关秘籍。我们收集学长学姐们亲笔撰写的课程锦囊、精心整理的学霸笔记，还有满载实战经验的实验报告模板。就像打开环境世界的多啦A梦口袋，你需要的学习装备，我们早已备好！

欢迎环院的同学（也欢迎其他学院同学）与我们共同建设平台，分享课程资源、笔记等资料，以便今后环院学子能够更为便捷地获取知识！
